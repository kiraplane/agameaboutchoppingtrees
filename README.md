# A Game About Chopping Trees Wiki

Independent English guide hub for **A Game About Chopping Trees** at
`https://www.agameaboutchoppingtrees.wiki`.

The launch site covers:

- a beginner cut, process, sell and replant loop;
- Axe, Endurance, Woodgrip, Chainfall and Handcar decisions;
- online co-op with personal money and upgrades;
- Birch and Oak zones, bridges, controls and sprint checks;
- all 15 official Steam achievements;
- demo/full-game separation, platforms, requirements and safe download links;
- WebSite, Organization, VideoGame, VideoObject, FAQPage, ItemList, Article and BreadcrumbList schema.
